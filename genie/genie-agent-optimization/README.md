# Genie Agent Optimization

Patterns, utilities, and evaluation assets for improving the quality of
Databricks Genie agents (Genie spaces) — moving from "it answers" to "it
answers correctly and consistently."

## Scope

- **Evaluation** — build benchmark question/answer (and question/SQL) sets and
  score Genie responses for accuracy and groundedness.
- **Instruction & example tuning** — iterate on Genie space instructions,
  trusted assets, and curated example SQL.
- **Semantic layer** — curate the Unity Catalog surface Genie reads: metric
  views, table/column descriptions, synonyms, and certified assets.
- **Iteration loop** — measure → change one thing → re-measure, tracking
  results over time.
