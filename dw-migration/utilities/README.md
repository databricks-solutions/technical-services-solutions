# DW Migration utilities

Tools that help you understand and plan a warehouse migration, on top of Lakebridge outputs.

| Utility | Description |
|---|---|
| [sts-lb-lineage](sts-lb-lineage) | Table-level lineage, process map, statistics, and impact analysis from Lakebridge Analyzer JSON (SQL and ETL), with an offline HTML viewer and optional Unity Catalog external lineage. |
