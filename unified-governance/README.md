# Unified Governance

Solutions and accelerators for unified governance with Databricks Unity Catalog. This track covers data and AI asset governance, access control, lineage, and compliance patterns.

## Projects

New work in this track lands here.

- [**Unity Gateway: model-service access and budgets with Terraform**](unity-gateway-terraform) — the options to manage Unity Gateway access (grants, ABAC GRANT policies), services and AI Gateway budgets in Terraform, and how to bring an existing setup under Terraform.
- [**ABAC Playbook: Data Classification & Policy Enforcement**](unity-catalog-abac) — use Data Classification to tag sensitive data, then enforce ABAC row filter and column mask policies (with a Terraform demo).
