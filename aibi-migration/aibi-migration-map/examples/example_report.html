L3

Metric View Blueprint

The 7 Metric Views that form the semantic layer — described as concepts, not code. For each: what it standardizes, the grain and time dimensions it owns, the metric drift it resolves, and every Tableau report you must open to build it correctly.

Why this layer is load-bearing. Metric logic today is copy-pasted across the estate and drifting — Gross Margin alone is defined 4 different ways across 8 workbooks, and Net Revenue 3. Two people asking "what was margin last quarter?" get different answers. Each Metric View below is the one place a definition lives, so a dashboard, a Genie space, and an App all return the same number. YoY and the 4-5-4 fiscal calendar are defined once here instead of re-derived in dozens of workbooks.

MV-SALESLoad-bearing
8reports163 sheets

Net revenue, units and basket economics off the estate's most-shared fact table (sales_fct, 8 workbooks touch it). Defines what 'net revenue', 'comparable sales' and 'average order value' mean once, for every channel.

  • Units sold
  • Average order value (AOV)
  • Comparable (comp) sales %
