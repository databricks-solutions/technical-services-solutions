# Data Engineering

## Projects

### [SDP Schema Evolution (Rescued Data Column)](./sdp-evolution/)

An agent-runnable Declarative Automation Bundles demo that handles schema evolution - column renames, type changes, and new columns - in Spark Declarative Pipelines using Auto Loader rescue mode and silver reconciliation via `_rescued_data`, with no full refresh.

### [Lakeflow Connect: SQL Server CDC](./lakeflow-connect/sql-server-cdc/)

DABs bundle that deploys Lakeflow Connect for SQL Server CDC — ingestion gateway, ingestion pipeline, and optional scheduled refresh — via a Unity Catalog connection.
